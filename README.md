# Premium Portfolio Template

A modern, dark, and interactive personal portfolio template built with pure HTML, CSS, and JavaScript.

Designed to work as both a personal portfolio and a digital identity / link-in-bio page.

## Features

- Fully responsive design
- Smooth animations and scroll reveals
- Mouse parallax effect on hero section
- Mobile-friendly navigation
- Clean and easy-to-customize code
- Dark cinematic aesthetic

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your browser
3. Customize the content in `index.html`
4. Update colors and styles in `css/style.css` if needed

## Customization

### Change Name & Content
Edit the text inside `index.html`:
- Name
- Title
- About section
- Projects
- Social links
- Email address

### Change Colors
Open `css/style.css` and modify the CSS variables at the top:

```css
:root {
  --accent: #7c6cff;
  --bg-primary: #0a0a0f;
  /* etc */
}
